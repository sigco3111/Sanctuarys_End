개요

생츄어리즈 엔드는 탑다운 액션 RPG 던전 크롤러입니다. 직업을 고르고, 야생과 끝없는 던전에서 몬스터를 처치하고, 더 좋은 전리품을 모으고, 패시브 스킬 숲을 키우며, 다섯 층마다 보스와 싸우기 위해 더 깊이 내려가세요.

목표

디센트를 최대한 깊이 내려가세요. 5층마다 보스가 있습니다. 정해진 엔딩은 없고, 깊이는 무한히 스케일됩니다.

순환

전투 → 전리품 → 마을 귀환 → 장비 판매·강화·재련·소켓 → 스킬 & 어빌리티 포인트 사용 → 더 깊이 잠수.

직업

전사, 마법사, 도적. 각각 고유한 기본 능력치, 성장, 피해 배율과 해금 가능한 액티브 스킬 목록을 가집니다.

이 위키는 게임 버전 v50(모듈식 sanctuary.html + game.js 빌드)을 다룹니다. 모든 수치는 게임의 데이터 테이블과 전투 공식에서 직접 가져왔습니다. 엔진이 값을 제한하는 경우 그 상한을 표기했습니다. 각 릴리스에서 바뀐 내용은 버전 역사를 참고하세요.

능력치 계산 방식

장비/레벨/숲이 바뀔 때마다 엔진은 파생 능력치를 대략 이렇게 다시 계산합니다:

피해 = base.dmg + gear.dmg + floor(STR × 0.5) 생명력 = (base.hpMax + gear.hp + VIT × 4) × (1 + 0.08·Toughness + %Life/100) 마나 = base.mpMax + gear.mp + ENG × 3 방어력 = gear.armor × (1 + 0.10·IronSkin + %Armor/100) 치명타 % = 5 + gear.crit + DEX × 0.1 + 직업 보너스 + 2·Precision + 2·DeadlyAim (상한 90%) 마나 재생 = 4/초 × (1 + 0.4·Meditation) + ENG × 0.2/초 + 장비 "+마나 재생" 생명력 재생 = VIT × 0.3/초 + 장비 "+생명력 재생" (최대 생명력 미만일 때만)

"base" 값은 레벨마다 직업의 HP/MP/DMG 성장치만큼 커집니다. 근접/주문 배율(전투 참고)은 능력치 창의 피해 숫자에 포함되지 않고 적중 순간에 적용됩니다.

전투 & 피해

피해 주기

근접 공격은 player.dmg × meleeMult × skillMult + rand(-3,3)을 굴립니다. 주문은 대신 spellMult를 씁니다. 배율은 직업과 패시브에서 나옵니다:

meleeMult = classMelee(전사 ×1.15) × (1 + 0.06·Berserk + (%Melee + %Damage)/100) spellMult = classSpell(마법사 ×1.30) × (1 + 0.06·ArcaneMind + (%Spell + %Damage)/100)

치명타

항목값
기본 치명타 확률5% + DEX×0.1% + 보너스, 상한 90%

피해 받기 (경감)

받는 피해는 정해진 관문을 거칩니다 — 회피 판정으로 아예 피할 수 있고, 이후 방어력, 고정 피해 감소, 속성 저항, 전투 함성, 마나 보호막이 차례로 남은 피해를 깎습니다:

1. 회피 → min(회피%, 60) 확률로 피해 0 [v49] 2. 방어력 → ×(1 − min(armor/(armor+40), 75%)) 3. 피해 감소 → ×(1 − min(고정DR%, 50)) [v49] 4. 저항 → ×(1 − min(속성저항% + 전체저항%, 75)) (속성별) 5. 전투 함성 → ×(1 − cryDR) 지속 중 6. 마나 보호막 → 남은 피해의 일부를 생명력보다 마나로 먼저 흡수

v49 저항은 속성별 + 전체 저항으로 적용되며 75% 상한 — 같은 상한이 직접 타격과 지속 피해 모두에 적용됩니다 (출혈은 물리 속성이라 저항 불가).

공격 & 이동 속도

공격 간격 (ms) = clamp((420 − DEX×1.2) × (1−Haste) × (1−IAS%/100), 150, 420) 표시 공격속도/초 = 1000 / 간격 → 2.38/s ~ 6.67/s 이동 속도 = 0.32 × (1 + min(이동보너스, 75%))

흡수, 적중 시 생명력 & 가시

  • 생명력 흡수 — 입힌 피해의 %만큼 회복.
  • 마나 흡수 — 입힌 피해의 %만큼 마나 회복.
  • 적중 시 생명력 v49 — 적중할 때마다 피해량과 무관하게 고정 생명력을 회복 (빠른 다단 히트 스킬에 강함).
  • 가시 — 근접 공격자가 때릴 때 고정 피해를 반사.

액티브 스킬

v49 액티브는 이제 6칸 액션 바로 돌아가고 어빌리티 포인트를 써서 해금합니다 — 레벨마다(레벨 2부터) 어빌리티 포인트 1개를 얻습니다. 어빌리티의 직업 레벨에 도달하고 포인트를 쓰면 내 것이 됩니다. 같은 포인트 풀로 각 스킬의 룬 트리 노드도 삽니다. 타격과 각 직업의 레벨 1 어빌리티는 무료입니다.

대부분의 스킬은 5등급까지 오릅니다. 스킬의 유효 등급은 권능 룬 노드와 +모든 스킬 보너스로 올라가며, 둘 다 스킬의 피해와 효과를 키웁니다.

v47 슬롯에 마우스를 올리면 실시간 툴팁이 뜹니다 — 현재 피해, 마나 소모, 재사용 대기, 적중 효과, 배정된 룬 — 스킬이 실제로 발사되는 계수표 그대로 계산하므로 숫자가 어긋나지 않습니다.
